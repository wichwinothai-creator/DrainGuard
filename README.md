# Drain Guard

ระบบตรวจจับระดับน้ำและแจ้งเตือนผ่าน Telegram

## Developed by
เทพสมุทรเฉพาะกิจ (Thep Samut Special Task Team)

## Features
- ตรวจจับระดับน้ำอัตโนมัติ
- แจ้งเตือนผ่าน Telegram
- ควบคุม Servo เปิด-ปิดทางระบายน้ำ
- ระบบเตือนด้วย LED และ Buzzer

## Hardware
- Arduino UNO
- ESP8266
- Water Sensor
- Servo Motor
